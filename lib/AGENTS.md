# lib/

## Purpose

Foundation utilities with no dependencies on `model/` or `view/`. First in the module order (`standard.md`).

## Ownership

- `const.lua` — mod-wide constants (names, keys, GUI element names, defaults)
- `util.lua` — generic Lua/Factorio helpers
- `log.lua` — logger used across model and view
- `ui_slices.lua` — sprite-slice definitions consumed by `data/sprites.lua`; regenerated by `scripts/import_ui_slices.ps1` from `audit/` mockup assets

## Local Contracts

- `lib` modules must not require anything from `model/` or `view/`
- New constants go in `const.lua`, not inline in consumers

## Work Guidance

- Follow `standard.md`

## Verification

- No automated tests; verify in-game
